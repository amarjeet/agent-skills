### 2.2 Quick Reference by Type

**Shading Blocks (Most Used)**
```
░  Light Shade
▒  Medium Shade
▓  Dark Shade
█  Full Block (Solid)
```

**Half & Eighth Blocks**
```
▀ ▄ ▌ ▐
▁ ▂ ▃ ▄ ▅ ▆ ▇
▏ ▎ ▍ ▌ ▋ ▊ ▉
```

**Quadrant Blocks**
```
▘ ▝ ▖ ▗   ▚ ▞   ▙ ▛ ▜ ▟
```

## 3. Quick Usage Guide

- Use a **monospace font** (Consolas, Courier New, Menlo, JetBrains Mono, etc.) for perfect alignment.
- These characters work in terminals, code editors, GitHub READMEs, and most modern applications.
- Combine **Box Drawing** characters for clean borders and **Block Elements** for shading and depth.
- For the cleanest look, stick to **Light Single Line** (`┌┐└┘─│`) + shading blocks (`░▒▓█`).
